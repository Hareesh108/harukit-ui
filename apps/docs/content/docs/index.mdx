Build consistent, accessible, and customizable interfaces while keeping your project lightweight and fully under your control.

## Features

- 🚀 **Zero Dependencies**: All components are self-contained; no external runtime libraries required.
- 🎨 **Fully Customizable**: You own the code—edit and style components directly in your project.
- ♿ **Accessible**: Built with accessibility in mind, following best practices for keyboard and screen reader support.
- 🎯 **TypeScript Ready**: Components are fully typed for type safety and developer productivity.
- ✨ **Lightweight Styling**: Styled using Tailwind CSS and CSS variables, with no extra styling libraries.
- 📦 **Flexible Integration**: Works seamlessly with any project setup; you control the dependencies entirely.
